# Local editing workspace

The interface centers two document roles: editable source prose and a reference whose writing style can be inspected before generation. Output and review findings appear only when there is a result.

Palette: cloud `#eef2f6`, paper `#ffffff`, ink `#17243a`, blue `#234ba8`, muted `#59677c`, review amber `#8c5b16`. Corbel provides clear interface typography; Constantia provides a distinct reading face for document comparisons. All fonts are local fallbacks; no external assets are fetched.

Layout: a wide source editor beside a narrower reference pane, followed by an editable profile and then a side-by-side source/result comparison. Text aligns left. The visible stages reflect actual work: Documents, Style, Rewrite. A compact progress area remains available during model loading and cancellation.

The deliberate visual emphasis is the document workspace itself. Avoid a marketing hero, repeated floating metric cards, decorative gradients, and model implementation settings in the writing flow. Preserve visible keyboard focus, mobile stacking, reduced-motion support, and plain-text rendering of all uploaded and generated content.

Review against the brief: this is an editing application, so a large promotional headline would obscure the upload task. The initial design was reduced to a wordmark, one explanatory sentence, and two clearly differentiated document panes.
